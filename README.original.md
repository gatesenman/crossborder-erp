# VivaHome ERP —— 跨境电商管理系统

这是一套标准的跨境电商 ERP，参考积加、领星、马帮、店小秘的业务模型和交互方式设计。它覆盖从商品、订单、采购、仓储、FBA 头程、物流到财务利润的完整闭环。界面全部是简体中文，采用企业级后台风格：
- 左侧分组折叠菜单；
- 顶栏包括面包屑、店铺切换、全局搜索、消息通知和用户菜单；
- 多标签页；
- 高密度表格，支持筛选、批量操作和分页；
- 抽屉详情和弹窗表单。

## 快速开始

```bash
# 1. 安装依赖（首次）
cd /workspace/erp/server && npm install
cd /workspace/erp/web && npm install && npm run build      # 构建前端到 web/dist

# 2. 初始化/重置演示数据（会清空并重建 server/data/erp.db）
cd /workspace/erp/server && npx tsx src/seed.ts

# 3. 启动服务（后端 API 和前端静态页面共用 8800 端口）
cd /workspace/erp/server && npx tsx src/index.ts
# 后台运行：
# (nohup npx tsx src/index.ts > /workspace/erp/server.log 2>&1 &)
```

访问地址：http://localhost:8800

## 功能模块

| 模块 | 页面 | 主要能力 |
|---|---|---|
| 仪表盘 | 经营概览 | 销售额、订单、毛利、广告、客单价、库存预警；待办事项；销售趋势；平台、站点占比；广告对比；库存预警 |
| 商品管理 | SKU / SPU / MSKU 配对 / 组合商品 | SKU 新增、编辑、详情（成本、尺寸、重量、供应商、安全库存）；平台 MSKU 与本地 SKU 配对；组合 SKU |
| 订单管理 | 订单处理 / 售后 / 审单规则 | 按状态分页签（待审核、待发货、已发货、已完成、异常、已取消）；手工建单；编辑；审核；按规则自动审单；智能匹配物流；分配仓库和物流；确认发货（生成运单号并扣减库存）；合并、拆分、取消；单笔利润 |
| 采购管理 | 采购计划 / 采购单 / 收货记录 / 供应商 | 按日均销量、在途、安全库存和目标天数生成补货建议，可一键生成采购单；采购单流程为草稿→待审核→已下单→部分到货→已完成；支持分批收货入库 |
| 仓储库存 | 库存查询 / 出入库与调拨 / 盘点 / 库存流水 / 仓库 | 按仓库查看可用、锁定、在途库存；其他入库和出库；调拨（在途→到货）；超库存校验；盘点盈亏确认；完整库存流水台账；本地仓、海外仓、FBA 仓 |
| FBA与头程 | FBA 货件 / 货代 | 创建货件计划；装箱信息；头程运费按重量、体积或数量分摊到 SKU；状态严格流转：计划中→已发货→运输中→已签收→已上架，不允许跳过状态；物流轨迹事件；上架后 FBA 仓库存增加 |
| 物流管理 | 物流渠道 / 物流规则 / 物流跟踪 / 物流商 | 渠道运费模板、时效；自动选择物流的规则；运单轨迹 |
| 财务管理 | 利润报表 / 订单利润 / 平台结算 / 汇率 | 按 SKU、店铺、站点、平台、日期五个维度出报表；重算利润；平台结算单；多币种汇率 |
| 广告概览 | 广告概览 / 广告活动 | 花费、销售额、ACoS、ROAS、点击率、转化率；活动列表 |
| 系统设置 | 店铺授权 / 用户 / 角色权限 / 操作日志 | 多平台店铺（Amazon、eBay、Shopify、TikTok Shop、Walmart、Temu）；用户和角色权限；操作日志 |

## 利润计算口径

```
订单毛利（CNY） = (销售额 − 平台佣金 − FBA 配送费 − 广告费) × 汇率
              − 商品成本（采购成本 + 头程分摊）− 尾程物流费 − 其他费用
毛利率 = 毛利 / 销售额（CNY）
```

- 汇率取自“财务管理 → 汇率管理”。
- 采购收货和 FBA 上架后会更新 SKU 的成本（含头程）。
- 在“利润报表”页点击“重算利润”，会按最新成本和汇率批量重算所有订单。

## 技术架构

- 前端：React 18、TypeScript、Vite、Ant Design 5（中文语言包）、ECharts。源码在 `web/src`，构建产物在 `web/dist`。
- 后端：Node.js、Express 5、better-sqlite3（SQLite 单文件数据库 `server/data/erp.db`），通过 tsx 直接运行 TypeScript。
  - 通用 CRUD 接口 `/api/r/:resource`，支持搜索、筛选、排序、分页和汇总。
  - 业务接口包括 `/api/orders/*`、`/api/purchase-orders/*`、`/api/stock-moves/*`、`/api/stocktakes/*`、`/api/fba/*`、`/api/finance/*`、`/api/purchase/suggestions`。
  - 登录后接口使用 Bearer Token 鉴权。
- 演示数据：6 个店铺、44 个 SKU、多个仓库、1200 个订单，以及采购单、FBA 货件、广告和结算数据（`server/src/seed.ts`）。

## 已知限制

- 平台 API 对接（拉单、同步库存、广告、结算）以及店铺授权都是模拟数据，没有连接真实的亚马逊等平台。
- “导出”只导出当前页的 CSV；“导入”目前只是占位入口。
- 权限只控制到菜单级，还没有做按钮级和数据级权限。
